# Surge-Modules

个人模块与自动化脚本（Surge / Loon 两套并存）。

## 目录结构

| 目录 | 内容 |
|---|---|
| `Surge/` | Surge 模块（.sgmodule） |
| `Loon/` | Loon 插件（.plugin），安装说明见 `Loon/README.md` |
| `Scripts/` | 两套共用的脚本（.js）及 QX 探针片段 |
